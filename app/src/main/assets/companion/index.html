Usar no iPhone como app

No Safari: Compartilhar → Adicionar à Tela de Início → Abrir como App. Abra pelo ícone para usar sem a barra de endereço. A conexão continua temporária: ao encerrar a sessão na TV, reconecte pelo novo QR. O painel não pode ocultar os controles do Safari dentro de uma aba comum.

Sessão temporária na rede local. Ao encerrar no Comic TV, o acesso pelo celular termina. Não é necessário instalar outro aplicativo.
