# Comic TV 1.1.19 · código 58

- Atualização de manutenção para conferir o fluxo de atualização integrado, da versão 1.1.18 para a 1.1.19, na TV Box.
- Mantém as funções da versão anterior, biblioteca, progresso, configurações e arquivos.

Na versão 1.1.18, abra Configurações → Atualizações → Verificar atualizações. Escolha Baixar atualização e, ao concluir, Instalar atualização. Confirme a instalação no Android; se solicitado, autorize o Comic TV a instalar aplicativos e volte para continuar.

Atualize por cima da instalação atual, sem desinstalar, limpar dados ou remover o USB. Depois, confira a versão 1.1.19 e a biblioteca preservada.
