## Arquitetura e limites

- Canal wlmb091/comic-tv-updates, update.json no latest release; APK por URL imutável da release. Somente HTTPS/hosts GitHub explícitos e esquema v1; metadados64KiB, APK64MiB, tamanho/hash/pacote/versão/minSDK/ABI/assinatura instalada conferidos. Sem token no app. Android verifica assinatura criptográfica na instalação e mantém confirmação/autorização de origem.
- Um download explícito, progresso/cancelar/retry, staging próprio em cache/updates, reserva64MiB, rename só após validação. Arquivo oferecido ao instalador é marcado e preservado até retorno; limpeza posterior só própria/segura. Atualizações não entram no backup nem limpeza de páginas. Sem desinstalar/mexerUSB/dados. Sem serviço contínuo ou PlayInAppUpdates; compatívelmin26 eBoxAndroid11.
- ViewModel da atividade com check automático uma vez por sessão, passivo; aviso Toast somente fora do leitor e sem foco. Aba Atualizações em Configurações, sem novo ícone lateral, checkmanual sempre disponível. Ao ir segundo plano cancelar check/download, exceto arquivo já oferecido/permissão/instalação. Instalar revalida antes de abrir Android; retorno consulta versão real, sem inferir sucesso só pelo callback.
- CI privado somente pushmain/workflow_dispatchmain, actions fixadas por SHA, testes/lint/ABI antes de assinatura. Keystore atual em secret cifrado; chave SSH de publicação dedicada com escrita somente no repo público. Nenhum PAT pessoal persistido no CI/app. Publicação usa branch temporária incoming/vX contendo sóAPK/update.json herdando workflow público, que verifica hash/assinatura, cria draft release, sobe arquivos e só então publica/latest, tag aponta main semAPK e branch temporária é removida. Código privado/keystore nunca são copiados ao canal. Branches temporárias evitam guardar binários na história principal. Publicador é idempotente e não substitui release já publicada; versão menor não vira latest.
- Credencial Git local usada somente para provisionar repo/deploykey/segredos viaAPI oficial (conector sem essas capacidades). Valores não impressos; secrets viaLibsodium sealedbox. Permissões atuais verificadasadmin/repo/workflow,PyNaCl instalado só no scratchwork para administração. Publicação autorizada pela proposta explícita aceita; preservar repositório fonte privado.
