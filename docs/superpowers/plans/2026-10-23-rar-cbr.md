# RAR/CBR Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** Importar e ler ZIP/CBZ e RAR/CBR pelo formato real, inclusive RAR com extensão CBZ.

**Architecture:** Fachada ComicArchive detecta assinatura e encaminha para ZIP ou Junrar 8.1.2. Originais e cache mantêm o contrato existente; arquivos internos continuam opacos ao usuário. RAR é extraído para destino temporário limitado, sem usar nomes do arquivo como caminhos de saída.

**Tech Stack:** Kotlin, Junrar 8.1.2, desugaring Android para APIs Java em minSdk 23.

**Spec:** Solicitação do usuário nesta conversa: adicionar RAR/CBR e validar com os dois arquivos Thanos; manter importação existente.

## Global Constraints

1 GiB por arquivo; 5.000 entradas; 32 MiB por página; 2 GiB descompactados; dicionário RAR limitado a 32 MiB. Rejeitar senha, multipartes, links, caminhos inseguros e tamanhos desconhecidos. Sem extrair arquivos arbitrários para diretórios. Nenhuma HQ do usuário no Git. Não alterar os outros incrementos planejados.
